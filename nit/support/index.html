Support

Help with Nit for iOS. For common questions, see the FAQ.

Email contact@bkrem.dev and include your iOS version and what you were doing when the problem happened. You'll normally hear back within a few days.

Common questions

Nit can't see my repository

Nit uses the GitHub tokens you add under Settings. A fine-grained token needs Contents and Pull requests read access to view a repository's PRs, and write access on both to review and merge. You can add several tokens; Nit picks the one that can see each repository.

Ask AI returns an error

Answers come from your own provider account — an Anthropic, OpenAI, or OpenRouter API key, or a ChatGPT sign-in. Check that the key is valid and has credit; Nit adds nothing on top of the provider's own limits.

Where is my data?

There is no Nit server and no account. Tokens and keys stay in the iOS Keychain on your device; opened pull requests are cached on device only. See the privacy policy.

Deleting your data

Delete the app. Everything Nit stores — tokens, keys, cached pull requests — lives on the device and is removed with it.
